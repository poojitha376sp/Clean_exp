===== DOCUMENT: requirement items (srs) =====
1.0
(informative) Overview

1.1 Introduction
(informative) Doorstop is a requirements management tool that leverages version control to
store and manage a project's documentation traced from specification through
implementation.

![Doorstop Logo](assets/logo-black-white.png "Doorstop Logo")

2.0
(informative) Composition Features

2.1 Identifiers
REQ003: Doorstop **shall** provide unique and permanent identifiers to linkable
sections of text.

2.2 Formatting
REQ004: Doorstop **shall** support formatting within linkable text.

2.3 Assets
REQ001: Doorstop **shall** support the storage of external requirements assets.

2.4 Importing content
REQ016: Doorstop **shall** be able to import content from other requirments
management tools.

2.5 Exporting content
REQ017: Doorstop **shall** be able to export content to interact with common
text/document tools.

3.0
(informative) Presentation Features

3.1 Viewing documents
REQ007: Doorstop **shall** provide a way to view requirements as a document.

3.2 Interactive viewing
REQ008: Doorstop **shall** provide a way to view document items interactively.

3.3 Baseline versions
REQ009: Doorstop **shall** provide the capability to baseline versions of
requirements.

4.0
(informative) Administration Features

4.1 Storing requirements
REQ011: Doorstop **shall** store requirements in a permanent and secure manner.

4.2 Change management
REQ012: Doorstop **shall** handle change management of the requirements.

4.3 Author information
REQ013: Doorstop **shall** associate requirements changes to existing developer
identification.

4.4 Scalability
REQ014: Doorstop **shall** be scalable to support thousands of requirements.

4.5 Installation
REQ015: Doorstop **shall** provide a lightweight installation method.
